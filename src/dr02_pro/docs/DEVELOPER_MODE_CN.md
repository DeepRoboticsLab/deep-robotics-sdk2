# DR02 Pro 开发者模式

[返回 DR02 Pro SDK 使用指南](../README_CN.md)

本文档说明 DR02 Pro 开发者模式的用途、三种控制模式，以及通过手柄或 SDK 示例切换模式的方法。开发者模式仅用于实机控制。

<a id="developer-mode"></a>

## 1. 模式说明

开发者模式用于向 SDK 开放机器人的运动控制权限，包含高层运动控制、全身关节控制和上半身关节控制三种模式。三种模式的控制范围不同，运行程序前应先确认目标程序所需的模式。

| 开发者模式 | 控制范围 | 适用示例 |
| --- | --- | --- |
| 高层运动控制模式 | SDK 通过 `/MOTION_STATE`、`/GAIT` 和 `/STEER` 等高层指令控制运动，关节由机器人内部控制策略执行 | [高层示例](EXAMPLES_CN.md#2-高层示例) |
| 全身关节控制模式 | SDK 通过 `/JOINTS_CMD` 直接控制全身关节 | [状态机](STATE_MACHINE_CN.md)、[低层示例](EXAMPLES_CN.md#1-低层示例) |
| 上半身关节控制模式 | SDK 通过 `/JOINTS_CMD` 控制腰部和双臂，腿部关节由机器人内部策略控制 | [低层示例](EXAMPLES_CN.md#1-低层示例) |

### 1.1 使用须知

- 进入开发者模式前，机器人应处于空闲状态。
- 进入开发者模式后，感知、定位和避障相关功能将关闭，请勿依赖这些功能保障运动安全。
- 三种开发者模式不能直接互相切换。切换目标模式前，应先停止 SDK 程序并完整退出当前模式，再选择并进入目标模式。
- 直接发布 `/JOINTS_CMD` 时，同一时间只允许一个发布者。

状态机所需的模式请参阅[状态机文档](STATE_MACHINE_CN.md)，各 Topic 示例所需的模式请参阅[Topic 示例](EXAMPLES_CN.md)。

## 2. 切换方式

1. **使用手柄切换：** 通过手柄设置并进入开发者模式，适合按照机器人现场操作流程控制实机。
2. **使用 SDK 示例切换：** 运行 `developer_mode_example`，通过 `/DEVELOPER_MODE` 服务和相关状态 Topic 完成模式切换，适合在终端中切换流程。

两种方式相互独立，不应同时操作。

<a id="handle-switching"></a>

## 3. 使用手柄切换

在手柄设置界面-辅助功能-开发者模式设置中开启开发者模式，并选择目标控制模式。选择结果会持续保存；模式不变时，后续无需重复配置。设置完成后，仍需按照下面对应的流程从手柄主界面进入模式。

### 3.1 高层运动控制模式

- 进入：
  1. 确认机器人处于空闲状态。
  2. 返回手柄主界面，通过左上角入口切换至开发者模式。
  3. 等待模式切换完成后，点击高层控制模式，等待启用完成。
- 退出：
  1. 在运行 SDK 的终端中退出程序，确认程序及相关控制 Topic 发布已经停止。
  2. 将机器人切换回空闲状态。
  3. 点击手柄主界面的退出开发。
  4. 确认机器人处于空闲状态后，通过主界面左上角入口退出开发者模式。

### 3.2 全身关节控制模式

- 进入：
  1. 确认机器人处于空闲状态。
  2. 返回手柄主界面，通过左上角入口切换至开发者模式。
  3. 等待模式切换完成后，点击全身控制模式，等待启用完成。
- 退出：
  1. 在运行 SDK 的终端中退出程序，确认程序及相关控制 Topic 发布已经停止。
  2. 点击手柄主界面的退出开发。
  3. 将机器人状态切回空闲后，通过主界面左上角入口退出开发者模式。

### 3.3 上半身关节控制模式

- 进入：
  1. 确认机器人处于空闲状态。
  2. 返回手柄主界面，通过左上角入口切换至开发者模式。
  3. 通过手柄界面操作，使机器人悬吊起立。
  4. 点击开始运动。
  5. 点击上半身控制模式，等待模式切换完成。
- 退出：
  1. 在运行 SDK 的终端中退出程序，确认程序及相关控制 Topic 发布已经停止。
  2. 点击手柄主界面的退出开发。
  3. 将机器人状态切回空闲后，通过主界面左上角入口退出开发者模式。

<a id="sdk-example-switching"></a>

## 4. 使用 SDK 示例切换

`developer_mode_example` 用于通过命令进入或退出实机开发者模式，并在危险阶段提示用户确认。

进入上半身模式时，示例还会使用 `/MOTION_STATE` 切换运动状态，并通过 `/MOTION_INFO` 确认状态变化。

```bash
ros2 run dr02_pro developer_mode_example high_level
ros2 run dr02_pro developer_mode_example whole_body
ros2 run dr02_pro developer_mode_example upper_body

ros2 run dr02_pro developer_mode_example exit
ros2 run dr02_pro developer_mode_example damping_exit
```

参数说明：

- `high_level`：进入高层运动控制模式，用于运行高层运动控制示例。
- `whole_body`：进入全身关节控制模式，用于运行状态机和全身关节控制示例。
- `upper_body`：进入上半身关节控制模式，用于运行腰部和双臂关节控制示例。进入 `RLControl` 前，机器人必须放在地面上且双脚稳定接触地面。
- `exit`：按照当前控制模式执行正常退出。上半身模式下会返回 `RLControl`，再继续退出开发者模式；机器人已经处于 `Idle` 时直接退出。
- `damping_exit`：快速退出当前控制，正常或异常状态下均可使用。机器人不在 `Idle` 时会先进入阻尼状态，可能失去主动支撑并倒地；已经处于 `Idle` 时跳过阻尼切换。

### 4.1 服务接口

`/DEVELOPER_MODE` 用于切换开发者模式。

| 项目 | 内容 |
| --- | --- |
| 服务名称 | `/DEVELOPER_MODE` |
| 服务类型 | `drdds/srv/StdSrvString` |
| 请求字段 | `command`，JSON 字符串 |
| 响应字段 | `result`，`success` 表示成功，其他值表示未完成或被拒绝 |

`command` 字符串使用以下 JSON 格式：

| 操作 | JSON 示例 | 作用 |
| --- | --- | --- |
| `enable` | `{ "Action": "enable" }` | 开启开发者模式权限，等待状态变为 `Enabled=true`、`Mode=0` |
| `set_mode` | `{ "Action": "set_mode", "Mode": 1, "Frequency": 500 }` | 选择具体的开发者控制模式，并设置关节控制数据频率，频率范围为 `0` 到 `500` |
| `disable` | `{ "Action": "disable" }` | 退出开发者模式权限 |

`set_mode` 的 `Mode` 值如下：

| `Mode` | SDK 名称 | 控制模式 |
| --- | --- | --- |
| `0` | `None` | 清除当前控制模式，不选择具体控制方式 |
| `1` | `UpperBody` | 上半身关节控制模式 |
| `2` | `WholeBody` | 全身关节控制模式 |
| `3` | `HighLevel` | 高层运动控制模式 |

<br>

`/DEVELOPER_MODE_STATUS` 用于确认当前状态，类型为 `std_msgs/msg/String`，`data` 字段是 JSON 字符串。例如：

```json
{"Enabled":true,"Mode":2,"Frequency":500}
```

`Enabled` 表示开发者模式权限是否开启，`Mode` 表示当前控制模式，`Frequency` 表示当前关节控制数据频率。高层运动控制模式不包含 `Frequency` 字段。示例通过该状态判断服务操作是否生效。

## 5. 紧急停止

发生异常或需要立即停止控制时，应优先按下手柄红色停止按钮。机器人状态恢复稳定后，应确认 SDK 程序和控制 Topic 已停止，再退出开发者模式。
