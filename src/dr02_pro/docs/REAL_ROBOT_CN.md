# DR02 Pro 实机部署与控制

[返回 DR02 Pro SDK 使用指南](../README_CN.md)

本文档说明控制 DR02 Pro 实机时的 SDK 环境、运行位置和开发者模式。SDK 可以在开发主机、AOS 主机（`10.21.33.103`）或 NOS 主机（`10.21.33.106`）上运行；AOS 主机和 NOS 主机均为机器人端计算设备。只要 ROS/DDS 网络互通，这些设备均可能直接控制实机。

## 使用流程

1. 选择 SDK 运行位置，完成网络、环境、代码部署和编译。
2. 根据目标程序确认所需的开发者模式，并使用手柄进入对应模式。
3. 在运行设备上启动程序。
4. 正常结束时先停止程序，再退出开发者模式；发生异常时使用手柄红色停止按钮。

## 环境与网络准备

SDK 依赖 ROS 2、[deep-robotics-msg](https://github.com/DeepRoboticsLab/deep-robotics-msg) 消息接口库。`deep-robotics-msg` 的 ROS 2 包名为 `drdds`。

消息接口库支持 deb 安装和源码编译两种方式，具体步骤请参阅 `deep-robotics-msg` 文档。通过 deb 安装时，加载 ROS 2 环境即可；通过源码编译时，还应加载消息接口库工作空间的 `install/setup.bash`。本文后续命令仅展示 ROS 2 环境加载。

| 运行位置 | IP 地址 | 环境状态 | 准备方式 |
| --- | --- | --- | --- |
| 开发主机 | 根据用户网络配置 | 建议使用 Ubuntu 22.04 或 Ubuntu 24.04 | 安装对应版本的 ROS 2，并安装或源码编译 `deep-robotics-msg` 消息接口库 |
| AOS 主机 | `10.21.33.103` | 需安装消息接口库 | 安装 `deep-robotics-msg` 消息接口库，并加载 ROS 2 和消息接口库环境 |
| NOS 主机 | `10.21.33.106` | 消息接口库已预装 | 无需单独安装消息接口库 |

连接 AOS 主机或 NOS 主机时，可以使用机器人 WiFi，也可以将网线插入机器人背部网口。网络连通后，通过 SSH 登录对应设备。

机器人 WiFi 密码与 SSH 登录密码不同。WiFi 名称、WiFi 密码和 SSH 密码均以交付资料或技术支持提供的信息为准。

## 部署与编译

### 在开发主机部署与编译

SDK 直接在开发主机上运行并控制实机时，开发主机必须通过网线连接机器人背部网口。

1. 将开发主机的有线网口 IP 和网关配置到 `10.21.33.*` 网段。网口 IP 可以使用未被占用的地址，例如 `10.21.33.100`。
2. 检查开发主机能否访问机器人设备：

   ```bash
   ping 10.21.33.103
   ```

3. 加载 ROS 2 和消息接口库环境，检查能否发现机器人 Topic：

   ```bash
   source /opt/ros/<ros-distro>/setup.bash
   ros2 topic list
   ```

4. 在开发主机上编译 SDK：

   ```bash
   colcon build --packages-up-to dr02_pro --cmake-args -DBUILD_PLATFORM=x86
   ```

> [!IMPORTANT]
>
> `ping` 成功仅表示 IP 网络连通。运行 SDK 前，还应确认 `ros2 topic list` 能够发现机器人 Topic。

### 在 AOS 主机（10.21.33.103）部署与编译

通过机器人 WiFi 或连接机器人背部网口访问 AOS 主机。在包含 `deep-robotics-sdk2` 目录的路径下执行以下命令将代码传输至 AOS 主机：

```bash
scp -r deep-robotics-sdk2 user@10.21.33.103:~/
```

AOS 主机需要安装 `deep-robotics-msg` 消息接口库。安装后提供的 ROS 2 包名为 `drdds`。登录后，加载 ROS 2 和消息接口库环境并编译 SDK：

```bash
ssh user@10.21.33.103
source /opt/ros/<ros-distro>/setup.bash
cd ~/deep-robotics-sdk2
colcon build --packages-up-to dr02_pro --cmake-args -DBUILD_PLATFORM=arm
```

### 在 NOS 主机（10.21.33.106）部署与编译

通过机器人 WiFi 或连接机器人背部网口访问 NOS 主机。在包含 `deep-robotics-sdk2` 目录的路径下执行以下命令将代码传输至 NOS 主机：

```bash
scp -r deep-robotics-sdk2 user@10.21.33.106:~/
```

NOS 主机已预装消息接口库，无需单独安装或源码编译 `deep-robotics-msg`。登录后，加载设备现有的 ROS 2 环境并编译 SDK：

```bash
ssh user@10.21.33.106
source /opt/ros/<ros-distro>/setup.bash
cd ~/deep-robotics-sdk2
colcon build --packages-up-to dr02_pro --cmake-args -DBUILD_PLATFORM=arm
```

### 部署与编译说明

> [!NOTE]
>
> - `--packages-up-to dr02_pro` 会编译 `dr02_pro` 及当前工作空间内的依赖包。
> - 相关依赖已经完成编译后，日常增量开发可使用 `--packages-select dr02_pro`。

> [!WARNING]
>
> 实机编译和控制不得启用 `BUILD_SIM=ON`。

## 开发者模式

### 模式说明

开发者模式用于向 SDK 开放机器人的运动控制权限，包含高层运动控制、全身关节控制和上半身关节控制三种模式。运行 SDK 前，应先确认目标程序所需的开发者模式，再通过手柄选择并进入对应模式。

| 开发者模式 | 控制范围 |
| --- | --- |
| 高层运动控制模式 | SDK 通过 `/MOTION_STATE`、`/GAIT` 和 `/STEER` 等高层指令控制运动，关节由机器人内部控制策略执行 |
| 全身关节控制模式 | SDK 通过 `/JOINTS_CMD` 直接控制全身关节 |
| 上半身关节控制模式 | SDK 通过 `/JOINTS_CMD` 控制腰部和双臂，腿部关节由机器人内部策略控制 |

状态机所需的开发者模式请参阅[状态机文档](STATE_MACHINE_CN.md)，各示例所需的开发者模式请参阅[Topic 示例](EXAMPLES_CN.md)。

### 通用要求

在手柄设置界面-辅助功能-开发者模式设置中开启开发者模式，并选择对应的控制模式。选择结果会持续保存；模式不变时，后续无需重复配置。此处选择不代表机器人已经进入对应模式，每次控制实机前仍需从手柄主界面进入开发者模式。

> [!IMPORTANT]
>
> - 进入开发者模式前，机器人应处于空闲状态。
> - 进入开发者模式后，感知、定位和避障相关功能将关闭，请勿依赖上述功能保障运动安全。
> - 三种开发者模式不能直接切换。切换目标模式前，应先停止 SDK 程序并完整退出当前模式，再前往设置界面选择目标模式。

### 高层运动控制模式

#### 控制范围

SDK 通过高层指令控制机器人运动，关节由机器人内部控制策略执行。该模式适用于高层运动状态、步态和速度控制示例。

#### 设置与进入

1. 在手柄开发者模式设置界面选择高层运动控制模式。
2. 确认机器人处于空闲状态。
3. 返回手柄主界面，通过左上角入口切换至开发者模式。
4. 等待模式切换完成后，点击高层控制模式，等待启用完成。

#### 运行程序

进入高层运动控制模式后，可按照上述通用运行命令启动[高层示例](EXAMPLES_CN.md#高层示例)。进入该模式不会直接改变机器人运动状态，后续运动状态应通过高层控制指令切换。

#### 正常退出

1. 在运行 SDK 的终端中退出程序，确认程序及相关控制 Topic 发布已经停止。
2. 将机器人切换回空闲状态。
3. 点击手柄主界面的退出开发。
4. 确认机器人处于空闲状态后，通过主界面左上角入口退出开发者模式。

### 全身关节控制模式

#### 控制范围

SDK 通过 `/JOINTS_CMD` 直接控制全身关节。该模式适用于状态机和全身关节控制示例。

#### 设置与进入

1. 在手柄开发者模式设置界面选择全身关节控制模式。
2. 确认机器人处于空闲状态。
3. 返回手柄主界面，通过左上角入口切换至开发者模式。
4. 等待模式切换完成后，点击全身控制模式，等待启用完成。

#### 运行程序

进入全身关节控制模式后，可按照上述通用运行命令启动[状态机](STATE_MACHINE_CN.md)或[Topic 示例](EXAMPLES_CN.md)中标注为全身关节控制模式的低层示例。

#### 正常退出

1. 在运行 SDK 的终端中退出程序，确认程序及相关控制 Topic 发布已经停止。
2. 点击手柄主界面的退出开发。
3. 将机器人状态切回空闲后，通过主界面左上角入口退出开发者模式。

### 上半身关节控制模式

#### 控制范围

SDK 通过 `/JOINTS_CMD` 控制腰部和双臂，腿部关节由机器人内部策略控制。该模式适用于腰部和双臂关节控制示例。

#### 设置与进入

1. 在手柄设置界面选择上半身关节控制模式。
2. 确认机器人处于空闲状态。
3. 返回手柄主界面，通过左上角入口切换至开发者模式。
4. 通过手柄界面操作，使机器人悬吊起立。
5. 点击开始运动。
6. 点击上半身控制模式，等待模式切换完成。

#### 运行程序

进入上半身关节控制模式后，可按照上述通用运行命令启动[Topic 示例](EXAMPLES_CN.md)中标注为上半身关节控制模式的低层示例。

#### 正常退出

1. 在运行 SDK 的终端中退出程序，确认程序及相关控制 Topic 发布已经停止。
2. 点击手柄主界面的退出开发。
3. 将机器人状态切回空闲后，通过主界面左上角入口退出开发者模式。

### 紧急停止

发生异常或需要立即停止控制时，应优先按下手柄红色停止按钮。机器人状态恢复稳定后，应确认 SDK 程序和控制 Topic 已停止，再退出开发者模式。

## 安全要求

> [!WARNING]
>
> - 控制实机前，应确认机器人已进入与目标程序匹配的开发者模式。
> - 首次实机运行具有运动控制功能的程序时，应在具备可靠吊绳保护的条件下进行测试。
> - `/JOINTS_CMD` 同一时间只允许一个发布者。
